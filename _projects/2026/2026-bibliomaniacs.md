abstract: >-
  Bibliomaniacs is a book review web application that enhances Ridgewood Public Library’s volunteer review service by streamlining personal information entry, organizing volunteer hour tracking, and utilizing user responses to provide informed recommendations. The main features of the app consists of a submission interface for volunteers requiring login, a volunteer dashboard where users can report/track their hours as well as generate automated certificates for cumulative volunteer hours, a reviewer/admin interface for reviewing and approving submissions, and a Mistral AI-powered recommendation feature (public-facing) displaying reviews and popular books, introducing greater variety and helping patrons discover new titles.
